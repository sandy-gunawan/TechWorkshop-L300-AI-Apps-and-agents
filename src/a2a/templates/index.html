How A2A Works

What is A2A (Agent-to-Agent)?

A2A is a protocol that lets AI agents discover, communicate, and collaborate with each other over HTTP. Each agent publishes an Agent Card (like a business card) describing its capabilities. Other agents can discover it and send tasks.

Flow: User → A2A Client → A2A Server → Agents

① User sends a message via the chat UI
② A2A Client wraps it as an A2A task and sends via HTTP POST
③ A2A Server receives the task, creates a task ID, and routes to the agent executor
④ ProductManagerAgent (orchestrator) analyzes the request and delegates to sub-agents using as_tool()

Sub-Agents (called as tools):

  • 📦 ProductAgent — retrieves products from catalog using get_products tool
  • 📣 MarketingAgent — improves descriptions, suggests marketing strategies
  • 🏆 RankerAgent — ranks and recommends products based on criteria

Key Difference from Multi-Agent:

In multi-agent, a router picks ONE agent. In A2A, the ProductManagerAgent decides at runtime which sub-agents to call — it can call multiple agents in sequence or combine their results. Sub-agents are exposed as tools via Microsoft Agent Framework's as_tool().
