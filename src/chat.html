How It Works

① User → Router

Message goes to the Handoff Service (LLM classifier) which picks the right agent.

② Router → Agent

🛍️ Cora (shopping) · 📦 Inventory (stock) · 🎨 Designer (design+images) · 🛒 Cart (no MCP) · ⭐ Loyalty (background)

③ Agent → MCP → ④ Tools

Agents call tools via MCP Server (stdio subprocess): 🔍 Products (Cosmos DB vector search) · 📋 Stock · 💰 Discount · 🖼️ Image Gen (DALL-E)

Auth: DefaultAzureCredential (managed identity). No API keys.
